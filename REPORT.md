# Звіт про виконання HW4 — OSINT Collector

## Джерело даних

Для виконання домашнього завдання розроблено Python-колектор
публічних дописів соціальної мережі Mastodon.

Джерело: https://mastodon.world/api/v1/timelines/public

Для отримання даних використано публічний REST API.
Авторизація для обраного endpoint не потрібна.

## Реалізація

Колектор отримує дописи невеликими сторінками та використовує
ідентифікатори публікацій для пагінації.

Проміжний прогрес зберігається в SQLite, тому після зупинки
програма може продовжити незавершений збір.

Дані зберігаються в таблиці posts у канонічному форматі:
id, author, url, date, text.

Унікальний ідентифікатор id використовується для захисту
від дублювання записів.

## Обмеження та обробка помилок

Для зменшення навантаження на API встановлено затримку
2 секунди між запитами та обмеження 5 запитів за запуск.

Реалізовано обробку HTTP 429 із використанням Retry-After,
а також повторні спроби з експоненційною затримкою
для тимчасових помилок сервера.

Помилки та результати запитів записуються до журналу.
Обробку HTTP 429, 403, 503 і помилок з'єднання перевірено
автоматизованими тестами з імітованими відповідями API.

Під час перевірених запусків було досягнуто встановленого
ліміту запитів за один запуск. Повне завершення тривалого
обходу окремо не перевірялося.

## Результати

Зібрано 404 унікальні публікації Mastodon.
Перевірка SQLite показала 0 дублікатів.

Повторний запуск успішно відновив збір зі збереженого місця.

Результат експортовано у файл sample_posts.csv,
який містить 404 записи в канонічному форматі.
