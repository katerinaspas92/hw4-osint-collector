# OSINT Collector — Mastodon

## Описание проекта

Python-проект для сбора публичных публикаций из социальной сети Mastodon.

Источник данных:
https://mastodon.world/api/v1/timelines/public

Сборщик использует публичный API Mastodon и сохраняет публикации
в локальную базу данных SQLite.

## Возможности

- Получение публичных публикаций через Mastodon API.
- Постраничная загрузка данных с использованием ID публикаций.
- Сохранение прогресса между запусками.
- Продолжение незавершённого сбора.
- Защита от дубликатов по уникальному ID.
- Пауза между HTTP-запросами.
- Обработка HTTP 429 и заголовка Retry-After.
- Повторные попытки при временных ошибках сервера.
- Логирование запросов и ошибок.

## Структура проекта

- collector.py — основной сборщик.
- api.py — HTTP-запросы и обработка ошибок.
- database.py — работа с SQLite.
- test_api.py — тесты обработки ошибок API.
- test_collector.py — базовый тест пагинации.
- requirements.txt — зависимости Python.

## Модель данных

Публикации сохраняются в таблицу posts:

- id — уникальный идентификатор публикации;
- author — автор публикации;
- url — ссылка на публикацию;
- date — дата публикации;
- text — текст публикации.

База данных: osint_data.db.

## Установка

Создать виртуальное окружение:

python3 -m venv .venv

Активировать окружение:

source .venv/bin/activate

Установить зависимости:

python3 -m pip install -r requirements.txt

## Запуск

Запустить сборщик:

python3 collector.py

При повторном запуске программа использует сохранённый прогресс
и продолжает незавершённый сбор.

## Тестирование

python3 test_api.py

python3 test_collector.py

## Настройки и ограничения

Источник: публичный API mastodon.world.

Для используемого публичного endpoint токен не требуется.
Секретные ключи в коде не хранятся.

Размер страницы: до 40 публикаций.
Максимум запросов за запуск: 5.
Задержка между запросами: 2 секунды.

При HTTP 429 учитывается заголовок Retry-After.
При временных ошибках применяются повторные попытки
с увеличением задержки (exponential backoff).

## Результаты

Во время проверки собрано 404 уникальные публикации Mastodon.

Данные сохранены в SQLite.
Повторный запуск успешно продолжил незавершённый сбор.
Проверка базы данных показала отсутствие дубликатов.

## Ограничения

Количество запросов за один запуск ограничено.
Полное завершение длительного обхода пока не проверено.
Доступность публичного API зависит от сервера Mastodon.
